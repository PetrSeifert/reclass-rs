reclass-rs — web frontend prototypes

Five design directions for a browser UI. Each one is clickable and runs on the same mock backend (shared/model.js): a fake attached Hollowfield.exe with live-changing memory, pointers, an encrypted pointer, enums, arrays, signatures and the [$GWorld] + 0x10 expression language. Right-click fields in any of them to change types, insert bytes and so on.

1 · Classic 01-classic

Faithful ReClass.NET look. Menubar, a toolbar with one-click type buttons, a dense colour-coded monospace tree, a properties pane and draggable floating windows. The closest to today's egui app.

densemouse-firstfloating windowsfamiliar

2 · Workbench 02-workbench

VS Code-style IDE. Activity bar, a class explorer, tabs so several instances are open at once, a column grid, an inspector with every interpretation, watch/problems/output panels and a Ctrl+K command palette.

multi-tabinspectorwatch listcommand palette

3 · Atlas 03-atlas

Light "paper" design with a light/dark toggle. You drill down through pointers like browser navigation (breadcrumbs, back/forward). The field list sits next to a colour-mapped hex dump; drag across bytes to define a field.

light themehex-firstdrill-down navlayout strip

4 · Terminal 04-terminal

Keyboard-first TUI. Vim motions (j k l h, dd, /), a : command line (:root, :type f32, :attach), fuzzy type picker. Phosphor, amber and neutral themes with an optional CRT effect.

keyboard-onlyvim keyscommandsthemes

5 · Constellation 05-constellation

Node-graph canvas. Every instance is a card; clicking a pointer port spawns the target card, connected by a wire (dashed for decrypted pointers). With "Share cards" on, pointers to an instance that's already open link to its card instead of duplicating it. Pan, zoom, auto-layout, minimap, floating glass panels.
